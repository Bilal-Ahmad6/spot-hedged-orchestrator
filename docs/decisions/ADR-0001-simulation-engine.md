# ADR-0001: Deterministic time-stepped simulation engine

**Status:** revised (2026-11-12) — supersedes the initial "use SimPy" decision.

## Context

We need 30-day simulated horizons at 1-minute resolution (43,200 ticks), ~2,800
runs for the pre-registered matrix, deterministic seeding, and a model detailed
enough to represent node lead time, drain ramps, reclaim events and a tail-latency
SLO.

The original decision was to use SimPy as the event engine. During the M1
prototype it became clear that the domain is **not** event-driven in the way SimPy
optimises for: node readiness and drain are continuous functions of time, and
every quantity can be derived from timestamps. A SimPy process per node would add
context-switching, make determinism harder to reason about, and slow the matrix.

## Decision

Use a **deterministic time-stepped loop** (`Simulation.run`) with 1-minute ticks,
plus pure functions for node capacity (`capacity_at(t)`), billing
(`billing_seconds(t0, t1)`) and latency. SimPy is removed from the dependency set.

## Consequences

- A 30-day run takes **~6 s** including 43,200 policy decisions and SLO
  evaluations; the full 2,800-run matrix is feasible on one machine.
- Determinism is trivial to test: same seed ⇒ byte-identical `summary.json`
  (there is a test for it).
- Node state cannot drift, because it is derived rather than mutated.
- Interruptions are generated by a seeded model and applied at tick boundaries;
  sub-minute effects (a 20 s drain) are represented by the capacity ramp, not by
  separate events. This is a modelling approximation, stated in the report.
- We lose the "SimPy" line from the tooling story, which is a fair trade for a
  model that can be re-run after every bug fix.

## Alternatives rejected

- **SimPy**: correct for queueing/process interaction, but our queueing is
  analytic and our nodes are time functions; it added cost without fidelity.
- **CloudSim Plus**: JVM, VM-level abstractions, heavy integration.
- **Custom event heap**: unnecessary once ticks are fixed at 1 minute.
